## About

This project analyzes the 2024 CDC/ATSDR Environmental Justice Index to examine the intersection of race, poverty, and environmental burden across the United States. It applies machine learning and statistical methods from QSS 45 to surface patterns of environmental injustice at the community level.

## Repository Structure

```
qss-45-final-project/
├── code/      # Jupyter notebooks for data processing and analysis
├── data/      # Raw and processed datasets
└── output/    # Generated figures and results
```

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab

## Getting Started

### Clone the repo

```bash
git clone https://github.com/obedf/qss-45-final-project.git
cd qss-45-final-project
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the notebooks

```bash
jupyter notebook
```

Then open the notebooks in the `code/` directory and run them in order.
